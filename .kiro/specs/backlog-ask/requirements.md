# Backlog #6 — Ask today's public feeds

Owner-approved scope: no dependencies or scorer changes. POST `/api/ask` retrieves today's scored default public feed items using existing embeddings/cosine/provider fallback, generates a cited answer, validates it completely, then streams framed HTTP source/answer/done events. This is buffered `generateText`, not live model-token streaming; no artificial pacing.

- Freeze request time once. Today means UTC calendar midnight through that instant, based on article `pubDate`; invalid/future dates and samples are excluded. Never silently broaden to older articles or browser subscriptions.
- Consider up to 60 eligible items in deterministic score/date order, matching existing embedding limits. Select at most five unique HTTP(S) sources by finite cosine similarity at or above 0.28, without semantic search's keyword bypass. 0.28 is an uncalibrated engineering default, not a measured relevance guarantee.
- Empty eligible corpus or successful retrieval below threshold returns deterministic `Not in today's feeds.` without generation. Missing/failed/incomplete embeddings return HTTP 503, never a false irrelevance claim. Total feed outage remains an upstream error; partial-feed warnings are disclosed.
- Reuse existing embedding helper and language-model factory/configured fallback order, default Gemini → OpenAI → Anthropic → Bedrock. Anthropic alone cannot supply embeddings. Preserve all summary/API/MCP/A2A contracts.
- Source labels, titles and URLs are server-built from retrieved items. Model output consists only of bounded statements and numeric citation labels. Fail closed on unknown/missing citation labels, model-supplied URL-like content, malformed output or empty answer. Render text, never model HTML or Markdown links. Citations constrain references, not proof of factual entailment.
- Strict bounded question and provider validation before paid work. Abort on request cancellation/timeout. Missing provider credentials: explicit 503; failed generation/validation across providers: 502 with no unsafe partial answer. Error responses never expose upstream secret-bearing messages.
- Ask UI is explicit-submit only and ephemeral: labeled form, Stop, loading/error/abstention/answer states, title/link citations and Today UTC/default-public-feeds disclosure. Say configured providers may charge. No automatic calls on typing.
- TopBar/CommandPalette launch one shared answer panel; integration waits for A's App/TopBar release. No storage writes or private/browser-local state sent to the server.
- Unit retrieval/citation guards use explicitly labeled stub embeddings only in `tests/ask.test.ts`. No runtime fixture/model paths. Real manual generation success requires credentials; absent credentials are an acceptance blocker, not fake QA.
