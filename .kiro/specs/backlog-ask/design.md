# Design — server slice and independent panel

`server/askPolicy.ts` owns pure UTC eligibility, cosine thresholding/deduplication and strict generated-answer validation. Numeric citations are transformed into server-built citation references; model text cannot supply links. Eligible sources require a valid HTTP(S) URL and a deterministic score. Keep max 60 candidates / five sources / six statements with bounded text.

`server/ask.ts` orchestrates live `loadItems`, `semanticScoreWithFallback`, and new `answerWithFallback`. Require a finite cosine result for every candidate; partial/missing vectors are retrieval-unavailable, not abstention. The generation helper remains in `server/ai.ts` so private model creation and fallback resolution are shared, never copied. It uses a dedicated Ask prompt, `generateText`, bounded output and cancellation, validates each provider's answer before acceptance, and never changes summary generation.

Native POST handler in `server.ts` shares the existing 192 KiB body bound. Body `{question, provider?}` is strictly validated (1–500 trimmed question characters, supported provider enum). Successful HTTP 200 uses NDJSON: exactly `sources` (scope, warnings, server-built sources), `answer` (validated statements or deterministic abstention), `done` (provider metadata). All data is buffered/validated before response creation; native stream frames have no pacing or live-token claim. Errors before headers: 400 validation, 503 retrieval/provider unavailable, 502 feeds/generation failed; sanitized fixed messages. Cancelled work is not retried on another provider.

`src/lib/ask.ts` contains shared wire schemas and a bounded incremental NDJSON reader with strict ordering/completion checks. `AskPanel.tsx` owns ephemeral request state/AbortController, rejects stale responses, clears answers on new requests, renders React text and safe citation anchors, and aborts on close/unmount. One `onOpenAsk(question?)` launch contract for CommandPalette/TopBar; no hidden event bus or alternate app entry point to evade locks. Server/panel can be checked independently, but no incomplete feature commit.

Modern-web forms/accessibility/security guidance informs explicit native form submission, labels, status announcements, keyboard cancellation and text-only rendering. UI mount, TopBar and App coordination remain blocked until A releases. Server AI helper ownership was explicitly released from B to C for this feature only.

Verification separates deterministic tests, live no-provider/empty-day API checks, built Worker regression checks, rendered panel behavior and credential-backed answer QA. Stubbed embeddings and labeled test articles live only in `tests/ask.test.ts`. No paid calls during this implementation. No claim that references prove all generated statements true; human provider QA must still assess grounding.
